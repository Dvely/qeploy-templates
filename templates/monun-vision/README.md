# 모눈비전

가상의 영상 보안 기업 웹사이트다. 제품 검색과 상세, 산업별 적용 사례, 기술과 학습 자료, 뉴스룸, 고객 지원을 포함한다. 제품 정보는 예시이며 문의 양식은 내용을 화면에 표시한다.

독립 실행 파일은 `src/`에 있다. 저장소에서 화면을 다시 생성하려면 `scripts/monun-vision/`의 데이터와 생성기를 수정하고 루트에서 `npm run build`를 실행한다. 배포되는 사진과 로고의 제작 기록은 `src/ASSET-PROVENANCE.json`, 이미지 프롬프트는 `src/image-prompts.json`에 있다.
