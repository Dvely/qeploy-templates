# 소담칸

생활용품과 식료품을 둘러보고 찜과 장바구니를 체험하는 정적 쇼핑몰 템플릿이다. 상품 8종, 카테고리 4종, 홈과 검색, 찜, 장바구니, 이용 안내를 포함한다.

- 상품명, 가격, 구성, 설명을 바꾸려면 `src/products.mjs`를 수정한다.
- 페이지 구성은 `src/build.mjs`, 화면 스타일은 `src/shop.css`, 브라우저 동작은 `src/shop.mjs`에 있다.
- 저장소 루트에서 `node templates/sodam-kan/src/build.mjs`를 실행하면 HTML을 다시 만든다. HTTP 서버로 `src`를 열어 미리보기할 수 있다.
- 찜과 장바구니는 현재 브라우저에 저장된다. 주문 버튼은 입력이나 전송 없이 상품 수량, 배송비, 예상 금액을 미리 보여준다.
- 로고와 화면은 이 프로젝트용으로 제작했다. 기획전 2장과 상품 사진 8장의 생성 프롬프트는 `src/image-prompts.json`에 있고, 파일별 출처와 해시는 `src/ASSET-PROVENANCE.json`에 기록했다. 상품 사진은 생성한 4×2 시트에서 개별 사진으로 잘랐다.
