# 세온 어패럴

가상의 어패럴 기업 사이트입니다. `src/index.html`을 정적 서버에서 엽니다. 저장소 루트의 `npm run build`로 갤러리 데모와 독립 소스 압축 파일을 만듭니다.

- 참고: https://www.hyungji-elite.com/ (2026-11-04 확인).
- 원본의 섹션 순서·화면 치수·반응형 분기와 Swiper·GSAP·ScrollTrigger·Lenis 기반 모션을 유지합니다. 세로 메인 슬라이드, 스크롤 문구 채움, 사업 카드, 영상 확대, 파트너 마퀴, 글로벌 영역과 ESG 카드 쌓기, 뉴스 슬라이드를 포함합니다.
- 이름·로고·사진·브랜드 영상과 회사 소개·사업·프로젝트 콘텐츠를 세온의 창작 예시로 교체했습니다. 생성 사진 6장과 Full HD 브랜드 영상, 새 SVG 워드마크를 로컬에 포함합니다.
- 회사소개·사회공헌·연혁·윤리경영·사업 3종·네트워크·공고·재무 2종·뉴스·기록 상세·위치·문의·데이터 안내, 총 17개 HTML을 연결합니다.
- 회사·제휴 브랜드·사업·공시·재무 정보와 연락처·위치는 모두 가상 예시입니다. 실제 기업의 수상·계약·임직원·재무 상태를 안내하지 않습니다.
- 문의 폼은 선택·입력·확인 흐름을 살펴보는 시연입니다. 개인정보를 외부로 전송하거나 저장하지 않습니다. 외부 지도·공시·SNS 및 번역 서비스와 원본 API 키를 포함하지 않습니다. 공유 버튼은 현재 페이지 주소를 복사합니다. 언어 메뉴는 선택 상태를 보여주는 시연입니다.
- `src/IMAGE-PROMPTS.md`에 내장 이미지 생성 도구로 제작한 최종 파일과 프롬프트를 기록했습니다.

정적 HTML과 `inc/`의 로컬 스타일·모션 라이브러리, `seon-local.js`를 함께 사용합니다. 원본 구조의 클래스와 애니메이션 연결을 유지하면서 문구와 이미지를 수정할 수 있습니다.
