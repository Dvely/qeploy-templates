# 아일게이트 소스

정적 HTTP 서버에서 `index.html`을 엽니다. 외부 라이브러리, 전용 글꼴, 원격 자산 없이 동작합니다.

- `catalog.mjs`: 가상의 상품 8개, 기획전 3개
- `build.mjs`: 정적 화면 19개 생성
- `site.css`, `site.js`: 디자인·검색·관심 상품·장바구니·통화·수령 시연
- `ASSET-PROVENANCE.json`, `image-prompts.json`, `assets/vector-notes.md`: 제작 근거와 파일 해시

원화 표시는 1달러당 1,350원의 시연용 고정값을 사용하며 결제·실시간 환율과 무관합니다. 장바구니·관심 상품·최근 본 상품·표시 통화만 브라우저에 보관합니다. 수령 화면의 예시 일정은 전송하거나 보관하지 않습니다. 주소는 학습용 예시입니다.
