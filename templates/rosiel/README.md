# 로지엘 뷰티

2026-11-06 권리 위험을 줄이기 위해 원본 사이트의 HTML·CSS·JS·Next.js 번들·WordPress 테마/플러그인·폰트·아이콘·미디어를 제거하고 새 화면과 동작으로 다시 작성한 독립 템플릿입니다. 원본과 같은 UI·애니메이션을 유지하는 버전이 아닙니다.

- 25개 독립 HTML과 기존 진입 경로를 연결합니다.
- 반응형 메뉴, 검색·분류·정렬·보관함, 상품 구성·수량·합계, 문의 입력·확인, 가이드 인쇄/다운로드를 제공합니다. 실제 접수나 결제는 진행하지 않습니다.
- 소스는 자기 완결형이며 정적 서버에서 index.html을 엽니다. node original-build.mjs로 site-config.json의 내용을 HTML에 반영합니다.
- 외부 라이브러리와 폰트 파일을 포함하지 않으며 시스템 서체를 사용합니다.
- ASSET-PROVENANCE.json과 THIRD_PARTY_NOTICES.md에 제작 자료를 기록했습니다. 제작 기록이 있는 생성 PNG/영상만 보존했으며 원본 사이트의 사진·로고·아이콘·동영상은 제거했습니다.
- 화면 코드의 적용 조건은 LICENSE.txt입니다. 생성 미디어의 독점권이나 상표 충돌 부재를 보증하지 않습니다.
- 대학 주소는 학습용 예시 위치이며 실제 사업장·입주·제휴 관계를 표시하지 않습니다.
