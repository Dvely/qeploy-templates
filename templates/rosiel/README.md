# 로지엘 뷰티

[ETUDE 국제 사이트](https://int.etude.com/)의 공개 화면을 기준으로, 원본 UI 구조와 애니메이션을 유지하고 새로운 가상 브랜드 **ROSIEL / 로지엘 뷰티**의 로고·문구·캠페인 사진·상품 이미지로 교체한 템플릿입니다. 참조 확인일은 2026년 10월 15일입니다.

## 유지한 UI와 효과

- 원본의 섹션 순서, 요소 클래스, 반응형 분기, 메뉴·검색·상품 옵션 컨트롤을 유지합니다.
- 원본 스타일 114개는 자산 URL을 제외한 치수·여백·색상·폰트·transform·transition·keyframes 규칙이 같습니다. 원본에서 쓰는 폰트와 아이콘 자산도 로컬로 포함합니다.
- 히어로는 원본 RevSlider의 전체 화면 높이, 4개 슬라이드, 레이어 진입·퇴장 프레임, 반응형 좌표, 가로 전환, 진행 표시, 키보드·터치 설정을 유지합니다.
- 전체 메뉴의 흐림·반투명 배경, 열림·닫힘과 모바일 메뉴/카테고리 탭을 원본 코드로 실행합니다.
- 스크롤 헤더 전환, 맨 위 이동, 브랜드 구간의 스크롤·스와이프 처리와 원본 마퀴·상품 갤러리·소셜 슬라이드를 유지합니다.
- 소셜 이미지 슬라이드는 원본 Elementor/Swiper 모듈로 자동 이동 5초, 전환 500ms, 반복·호버·상호작용 일시정지 조건을 유지합니다.

참조 사이트에서 존재하지 않는 선택 박스·상세 탭·공유 버튼·수상 배너, 로드되지 않은 레거시 OwlCarousel에 접근하는 부분에는 존재 여부 검사만 추가했습니다. 실제 요소가 있는 경우의 동작이나 애니메이션 시간은 변경하지 않았습니다.

## 새 콘텐츠와 연결

홈·컬렉션·브랜드·4개 제품 이야기·12개 상품 상세·공지·이용 안내와 미디어 화면, 총 22개 HTML을 연결합니다. 메뉴의 세부 카테고리는 같은 원본 컬렉션 UI에서 가상 상품을 필터링합니다. 검색은 원본 팝업 프레임에서 결과를 보여주고 컬렉션·상세 화면으로 이어집니다. 원본 색상 선택과 갤러리·상세 탭 동작을 유지합니다.

Built-in `image_gen`으로 캠페인 사진 4개와 상품 컷아웃 8개를 생성했습니다. 편집 가능한 로고·문구·상품 정보 그래픽은 SVG입니다. 사진 자체의 PNG 원본은 그대로 저장하고, 원본 비율의 SVG 프레임에 배치했습니다. [image-prompts.json](image-prompts.json)에 파일 경로·프롬프트·투명 배경 여부를 기록합니다. 원본 영상 콘텐츠를 대신하는 9초 캠페인 클립은 생성한 사진으로 구성하며 원본 영상 레이어·플레이어 구조에서 재생합니다.

상품·가격·브랜드·연락처는 시연용 콘텐츠입니다. 실제 구매·결제·회원 가입·외부 판매처 주문은 진행하지 않습니다. WordPress 서버 응답은 로컬 데이터로 대체하고, 원본의 광고 추적 및 외부 인증·게시 요청은 포함하지 않습니다.

## 검증 및 출처

- 1280×720 데스크톱과 390×844 모바일에서 히어로·헤더와 홈의 8개 섹션 크기·위치를 원본과 비교했습니다. 새 소개 문구의 줄 수도 맞췄습니다.
- 전체 22개 화면을 데스크톱과 모바일에서 열어 누락 이미지 및 문서 가로 넘침을 확인했습니다.
- 히어로 페이지 이동, 전체 메뉴, 검색 결과/필터, 상품 상세 링크 및 원본 옵션·갤러리 컨트롤을 확인했습니다.
- 원본 CSS·JS 파일과 모션 속성의 비교는 [verification.json](verification.json) 및 [source-assets.json](source-assets.json)에 기록합니다.
- UI 코드·라이브러리·폰트·일반 컨트롤 아이콘의 출처는 위 참조 사이트 및 원본 파일에 표기된 제공자입니다. 원본 저작권·라이선스 헤더를 유지하며, 해당 UI 엔진이나 폰트를 자체 창작물로 주장하지 않습니다. 새 사진·로고·카피는 별도 콘텐츠입니다.

저장소 루트의 `npm run build`로 `/t/rosiel/` 데모와 자기 완결형 `site/src/rosiel.tar.gz` 씨앗을 생성합니다. 원본 UI를 유지하려면 스타일·모션 모듈 대신 이미지·본문·`rosiel-data.js`의 시연 데이터를 편집하세요.
