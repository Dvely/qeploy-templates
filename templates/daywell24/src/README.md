# 데이웰24

[이마트24 공개 사이트](https://emart24.co.kr/)의 UI 구조와 모션을 유지하고, 가상의 편의점 브랜드 **DAYWELL24 / 데이웰24**로 콘텐츠를 교체한 템플릿입니다. 2026년 10월 14일 확인한 공개 화면을 기준으로 작업했습니다.

홈 화면의 고정 `QUICK` 메뉴와 `KR` 언어 선택 메뉴는 사용자 요청에 따라 제거했습니다. 한국어·영어 홈 모두 동일하게 적용합니다.

## 유지한 UI와 모션

- 원본 HTML의 레이아웃 클래스·섹션 순서·컨트롤 구조와 원본 CSS의 치수, 폰트, 반응형 분기, transition, transform, keyframes를 유지했습니다. CSS 37개는 자산 URL을 제외한 규칙이 동일합니다.
- 헤더의 스크롤 축소와 로고 전환, 모바일 전체 메뉴의 세 겹 배경 전환과 하위 메뉴 열림을 원본 모듈로 실행합니다.
- 창업 안내 슬라이드: 원본 인라인 스크립트 그대로입니다. 자동 이동 3초, 마지막 구간 대기 8초, 되감기 400ms를 유지합니다.
- 이벤트: 원본 Swiper 4.5.1, 이동 600ms, 자동 이동 3초, 가운데 정렬, 반복 슬라이드, 페이지 표시와 일시정지/이전/다음 동작을 유지합니다.
- ONLY 상품과 월간 행사 상품의 탭·슬라이더는 원본 인라인 스크립트를 유지합니다.
- 스크롤 진입은 원본 `commonJs/ScrollObserver.js`를 그대로 사용합니다. `rootMargin: 118px`, `threshold: 0` 및 섹션의 0.7초 전환을 유지합니다. 원본의 모바일 모션 분기도 그대로 적용됩니다.
- APP 소개의 데스크톱 fullPage 화면 전환과 모바일 스크롤/다운로드 바도 원본 구조를 유지합니다.

원본의 제거된 `.mainBannerView`, 존재하지 않는 PDF 링크·추천 배너, 초기화되지 않은 모바일 `fullpage_api` 참조에만 존재 여부 검사를 추가했습니다. 활성 UI의 속도나 전환 조건은 수정하지 않았습니다.

## 교체한 콘텐츠

로고, 슬로건, 히어로 캐릭터, 창업 카드, 이벤트 배너 20개, 상품 사진, 매장 사진, 브랜드 안내와 연락처를 새 브랜드 콘텐츠로 교체했습니다. 주요 이미지의 원본 캔버스 비율과 DOM 위치를 유지합니다. 추가 콘텐츠 이미지 333개의 원본 크기도 확인해 새 SVG의 캔버스 비율에 반영했습니다. 참조 사이트에서 빈 경로 또는 손상된 응답을 반환한 3개는 자체 대체 그래픽을 사용합니다. 본문은 Noto Sans KR, 주요 제목은 원본의 Paperlogy 폰트입니다.

Built-in `image_gen`으로 사진·상품 컷아웃·캐릭터 12개를 생성했습니다. PNG 원본은 `images/daywell24-*.png`, 프롬프트와 투명 배경 여부는 [image-prompts.json](image-prompts.json)에 기록했습니다. 새 로고·프로모션 텍스트·아이콘 변형은 편집 가능한 SVG입니다. 소개 영상은 새 매장 사진으로 만든 6초 MP4이며 원본의 영상 플레이어 UI를 사용합니다.

## 연결된 화면

홈을 포함해 57개의 독립 HTML 화면이 있습니다. 브랜드, 상품, 이벤트, 매장, APP/서비스, 창업 안내/상담, 고객센터, 공지, 정책과 사이트맵을 로컬 경로로 연결했습니다. 상세 페이지의 원본 UI 프레임에 새 콘텐츠를 넣었으며 추가 이벤트 화면은 같은 상세 프레임을 사용합니다.

상품과 상담은 **정적 데모**입니다. 실제 구매·상담 접수·개인정보 저장·본인인증은 하지 않습니다. 서버 응답은 `daywell24-adapter.js`의 가상 데이터로 대체합니다. 매장 지도는 외부 지도 SDK 대신 원본 검색 프레임 안의 가상 위치도이며, 가상 지역·검색·확대·축소를 제공합니다. 원본 사이트의 서버, 실시간 지도, 앱 다운로드와 외부 인증 서비스를 복제한 것은 아닙니다.

## 검증과 출처

- 전체 57개 HTML의 링크·이미지·CSS 자산 연결을 검사했습니다.
- 390px 모바일 및 1440px 데스크톱에서 전체 화면을 열어 누락된 이미지와 문서 가로 넘침을 확인했습니다.
- 슬라이드 수동 이동/반복, 재생 전환, 월간 상품 탭, 매장 검색, 모바일 메뉴와 스크롤 헤더를 브라우저에서 확인했습니다.
- [verification.json](verification.json)에 CSS·모션 동일성 및 화면 검사 결과를 기록합니다. [source-assets.json](source-assets.json)은 공개 CSS/JS 원본과 로컬 파일의 SHA-256 기록입니다.
- 공개 UI의 CSS/JS와 일반 컨트롤 아이콘 출처는 위 참조 사이트입니다. 이를 새 브랜드의 디자인 저작물로 주장하지 않습니다. 원본 라이브러리의 저작권·라이선스 헤더를 보존했습니다. 폰트 출처·라이선스는 `licenses/`에 있습니다.

## 실행 및 편집

저장소 루트에서 `npm run build`를 실행하면 `/t/daywell24/` 데모와 자기 완결형 `site/src/daywell24.tar.gz` 씨앗을 생성합니다. 원본 모션을 유지하려면 CSS와 모션 모듈 대신 이미지·본문·`daywell24-data.js`를 편집하세요. 원본 클래스에 남아 있는 식별자는 모션 연결을 위한 코드명이며 화면의 브랜드 표기가 아닙니다.
