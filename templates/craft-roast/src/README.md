# CRAFT & ROAST · 크래프트 앤 로스트

Stitch의 모던 심플 카페 시안을 바탕으로 만든 자기 완결형 HTML/CSS/JavaScript 템플릿입니다. `index.html`을 정적 서버에서 열면 됩니다. 별도의 패키지 설치나 외부 폰트·이미지 요청이 필요하지 않습니다.

- `index.html`: 로스터리 홈, 시즌 메뉴·페어링·공간·파트너십 소개
- `craft-roast-menu.html`: 라떼·피낭시에 페어링 상세와 옵션별 가격
- `craft-roast-beans.html`: 게이샤 원두 상세, 분쇄·수량·구독 선택과 브루잉 안내
- `craft-roast-stores.html`: 지역·서비스별 매장 탐색, 가맹 모델과 상담 양식
- `craft-roast-data.js`: 메뉴와 상품의 공통 데이터
- `craft-roast.js`: 메뉴 필터, 장바구니·주문 모달, 매장 탐색과 문의 양식
- `craft-roast.css`: 오프라인 스타일과 반응형 화면
- `images/`, `fonts/`, `licenses/`: 로컬 일러스트레이션, 글꼴과 라이선스

브랜드·상품·매장·후기·가맹 비용은 가상의 예시입니다. 주문·픽업·구독·문의·로그인은 화면 체험이며 실제 결제나 접수가 이루어지지 않습니다. 입력한 연락처·주소·비밀번호·후기는 저장하거나 전송하지 않습니다. 장바구니에는 상품과 옵션·수량을, 보관함에는 원두 식별자를 브라우저에 저장합니다.

원본 시안: Stitch 프로젝트 `13625598239509435124`의 크래프트 앤 로스트 모던 심플 홈·메뉴·원두·가맹 화면.
