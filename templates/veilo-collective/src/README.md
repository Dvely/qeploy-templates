# 베일로 컬렉티브 소스

정적 HTTP 서버에서 `index.html`을 엽니다. 영문 홈은 `en-index.html`입니다. 외부 폰트나 스크립트, API는 필요하지 않습니다.

- `content.mjs`: 한영 브랜드, 소식과 메뉴
- `build.mjs`: 정적 한영 페이지 32개 생성. 수정 후 `node build.mjs` 실행
- `site.css`, `site.js`: 화면 및 동작
- `ASSET-PROVENANCE.json`, `image-prompts.json`: 제작 내역과 생성 프롬프트

표시된 동양미래대학교 주소는 학습용 예시이며 실제 사업장이나 제휴 관계를 뜻하지 않습니다. 재무·투자 실적, 실제 채용 공고, 제품 효능을 주장하지 않습니다.
