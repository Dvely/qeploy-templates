# 프리즘온

정밀 광학과 영상 부품 기업을 소개하는 가상 사이트다. 홈 배너, 사업 분야, 기업 자료, 기술 노트, ESG와 채용 안내를 둘러볼 수 있다.

내용은 `src/content.mjs`, 화면 생성은 `src/build.mjs`에 있다. 저장소 루트에서 `node templates/prismon-optics/src/build.mjs`를 실행하면 정적 페이지를 다시 만들 수 있다. 이미지 생성 프롬프트와 자산 출처는 `src/image-prompts.json`, `src/ASSET-PROVENANCE.json`에 기록했다.
