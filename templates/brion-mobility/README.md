# 브리온 모빌리티

차량 소프트웨어, 제어기, 연결과 충전 기술을 소개하는 가상 기업 사이트다. 홈에서 회사 소개, 협업과 문의로 이동할 수 있다. 문의는 입력 내용을 현재 화면에서 미리 보여준다.

내용은 `src/content.mjs`, 화면 생성은 `src/build.mjs`, 인터랙션과 스타일은 `src/site.mjs`와 `src/site.css`에 있다. 저장소 루트에서 `node templates/brion-mobility/src/build.mjs`를 실행한 뒤 HTTP 서버로 `src/`를 열면 미리볼 수 있다. 사진과 로고의 출처는 `src/ASSET-PROVENANCE.json`, 이미지 생성 프롬프트는 `src/image-prompts.json`에 있다.
