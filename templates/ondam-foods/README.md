# 온담식품

가상 식품 브랜드의 정적 웹 템플릿입니다. `index.html`을 열거나 이 폴더를 정적 서버로 실행합니다. 외부 서비스 연결이나 설치 과정은 없습니다. 벡터 애니메이션 데이터는 `ondam-motion-data.js`에 포함되어 파일 직접 열기에서도 별도 JSON 요청 없이 표시됩니다.

## 화면과 동작

- 참고: https://www.otoki.com/main/ (2026-10-17 확인)
- 원본의 메인 섹션 순서, 전체 화면 히어로, 데스크톱 헤더와 모바일 메뉴, 도형 안의 교차 사진 전환, 이미지 모자이크, 확장형 지속가능경영 카드, 제품 슬라이드, 뉴스·레시피·소셜 카드, 푸터 배치를 유지했습니다.
- 메인 슬라이드 7개, 제품 슬라이드 6개. 자동 이동·이전/다음·재생/정지와 스와이프를 지원합니다. 원본 영상은 새 정지 이미지로 교체했습니다.
- 새 로고, 한글 카피, 상품·레시피·뉴스와 사진을 사용합니다. 실제 기업의 인증·주소·연락처·실적을 표시하지 않습니다.
- 소개, 지속가능경영, 제품, 브랜드, 소식, 고객센터, 전체 메뉴, 개인정보 안내, 검색 및 16개 콘텐츠 상세로 연결됩니다.
- 외부 분석·추적·챗봇·조회수 전송·서버 검색을 제거했습니다. 검색은 `ondam-data.js`를 현재 브라우저에서 필터링하며 문의·주문을 실제 접수하지 않습니다.

## 파일

사용하지 않는 원본 하위 화면 스타일과 자산은 제거했습니다. `css/common.css`와 `js/common.js`, `js/ondam-home.js`는 원본의 배치와 UI 동작을 보존합니다. 브랜드별 콘텐츠 변경은 `index.html`, `ondam-*.html`, `ondam-data.js`, `css/ondam-content.css`, `images/`에서 진행합니다. 각 소스는 이 폴더 안의 상대 경로만 참조합니다.

## 이미지 생성 기록

메인 사진 `images/ondam-seasonal-table.png`는 내장 이미지 생성 도구로 제작했습니다. 요청: 가상 식품 브랜드를 위한 16:9 음식 광고 사진, 따뜻한 햇살이 비치는 나무 식탁에 채소 카레·샐러드·버섯·국을 차린 장면, 오른쪽에 음식과 왼쪽에 여백, 사진에 문자·상표·인물 없음. 추가로 라면, 제철 채소, 요리하는 두 사람, 채소 군만두 사진 4장을 내장 이미지 생성 도구로 제작했습니다. 모두 따뜻한 햇살의 16:9 광고 사진이며 문자·로고·포장 상표를 넣지 않았습니다. 사용한 최종 파일은 `images/ondam-noodle.png`, `ondam-harvest.png`, `ondam-kitchen.png`, `ondam-dumplings.png`입니다. 이전 사진과 사용하지 않는 원본 자산은 제거했습니다.
