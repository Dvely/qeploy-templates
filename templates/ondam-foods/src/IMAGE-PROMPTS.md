# 보존한 제작 사진 기록

기존 제작 README의 자체 생성 사진 설명입니다.



메인 사진 `images/ondam-seasonal-table.png`는 내장 이미지 생성 도구로 제작했습니다. 요청: 가상 식품 브랜드를 위한 16:9 음식 광고 사진, 따뜻한 햇살이 비치는 나무 식탁에 채소 카레·샐러드·버섯·국을 차린 장면, 오른쪽에 음식과 왼쪽에 여백, 사진에 문자·상표·인물 없음. 추가로 라면, 제철 채소, 요리하는 두 사람, 채소 군만두 사진 4장을 내장 이미지 생성 도구로 제작했습니다. 모두 따뜻한 햇살의 16:9 광고 사진이며 문자·로고·포장 상표를 넣지 않았습니다. 사용한 최종 파일은 `images/ondam-noodle.png`, `ondam-harvest.png`, `ondam-kitchen.png`, `ondam-dumplings.png`입니다. 이전 사진과 사용하지 않는 원본 자산은 제거했습니다.
