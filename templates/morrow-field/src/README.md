# 모로우 필드

관찰·감각·소재·대화를 주제로 구성한 가상의 디자인 랩 템플릿입니다. 자체 작성한 화면·코드·벡터와 새 생성 이미지를 사용합니다.

## 화면과 흐름

홈 → 공간 목록·필터 → 공간 상세 → 프로그램 목록·상세 → 날짜·시간·인원 선택 → 안내 확인 → 방문 구성 보관 → 나의 방문·인쇄·삭제·복원으로 연결됩니다. 소개, 저널 검색·분류·상세, 이용 안내·FAQ, 시연 이용 안내를 포함한 19개 페이지입니다.

예약은 서버 전송·결제가 없는 로컬 시연입니다. 이름·연락처·이메일 입력이 없고, 선택한 프로그램·일정·인원과 임의 구성 번호만 브라우저에 저장합니다. 저장이 차단되면 실패를 표시합니다.

## 실행과 수정

빌드된 `src/index.html`을 열거나 정적 서버로 `src/`를 제공합니다. 런타임에는 외부 의존성·네트워크 API·데이터 fetch가 필요하지 않습니다. 내용은 `content.mjs`, 디자인은 `site.css`, 동작은 `site.js`, 공통 HTML은 `build.mjs`에서 수정합니다.

```sh
node build.mjs
```

자산·제작 기록을 검토하고 배포 검토 파일을 갱신한 뒤 루트 빌드를 실행합니다. 일반 빌드는 미검토 변경을 자동 승인하지 않습니다.

## 디자인과 제작 기록

사용자가 제공한 DBCUT 링크는 현대자동차그룹 UX 스튜디오로 연결되었습니다. 소개·공간 탐색·프로그램·방문 안내라는 일반적인 기능 요구만 참고했습니다. 원본의 두 줄 헤더, 영상 히어로, 기업 그래픽·레이아웃·전용 모션은 복제하지 않았습니다. 별도의 단일 헤더·에디토리얼 타이포그래피·공간 레일·프로그램 행 목록·단계별 방문 계획으로 새로 구성했습니다.

원본 코드·이미지·로고·폰트·문구를 다운로드하거나 이 템플릿에 포함하지 않았습니다. 새 사진은 원본 이미지를 입력하지 않은 내장 이미지 생성 도구 결과이며 정확한 프롬프트는 `src/image-prompts.json`, 벡터 제작 기록은 `src/assets/vector-record.json`에 있습니다.

`src/ASSET-PROVENANCE.json`, `src/THIRD_PARTY_NOTICES.md`, `src/LICENSE.txt`에서 항목별 제작·이용 범위를 구분합니다. 독립 제작은 모든 제3자 권리 부재나 상표 등록 가능성을 보증하는 것은 아닙니다.

대학 주소는 학습용 예시 위치이며 실제 사업장·입주·제휴 관계를 의미하지 않습니다.
