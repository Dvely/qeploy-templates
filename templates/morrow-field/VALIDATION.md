# 모로우 필드 검증 기록

검증일: 2026-11-07

## 코드·배포물

- 전체 카탈로그 19종 빌드 통과. 모로우 필드 19개 화면 생성.
- 19개 HTML의 로컬 링크·자산·앵커 확인. 누락 및 외부 자산 참조 없음.
- 모로우 필드 소스 압축물 36개 파일의 목록·해시가 검토 기록과 일치.
- JavaScript·생성기 구문 검사 통과. 원본 기업 브랜드·전용 웹폰트 참조 없음.
- 배포 검증 규칙의 기존 테스트 4개 통과.

## 브라우저

- 320×780, 390×844, 1280×800에서 19개 화면씩 확인. 문서의 가로 넘침 및 로드가 끝난 이미지의 손상 없음. 의도한 공간 카드 가로 탐색은 문서 전체 넘침과 구분.
- 모바일 메뉴 열기·메뉴 이동·닫기, 배경 main/footer의 inert 적용 및 복귀 확인.
- 프로그램 목록 → 감각 메이커 상세 → 해당 프로그램이 선택된 방문 화면 연결 확인.
- 날짜·시간 미선택 시 안내, 구성 확인 미완료 시 보관 차단 확인.
- 날짜·시간·2명 선택 → 안내 확인 → 구성 보관 → 나의 방문 이동 → 새로고침 후 유지 → 삭제 → 복원 → 테스트 기록 삭제 확인.
- 2층 공간 필터 1개 결과, 저널 ‘손끝’ 검색 1개 결과 및 없는 검색어의 결과 없음 상태 확인.
- 홈 공간 레일의 다음 버튼으로 가로 이동 확인.
- 임시 반응형 뷰포트는 검증 후 기본 크기로 복구.

HTTP 정적 서버에서 검증했다. 브라우저 보안 정책이 file: 탐색을 차단해 직접 파일 실행은 확인하지 않았으며 우회하지 않았다. 실제 예약·결제·개인정보 입력·외부 전송은 구현하지 않았다. 실제 브라우저 인쇄 실행은 별도 확인하지 않았다.

## 제작 자료

사진 1개는 원본 이미지를 입력하지 않은 OpenAI 내장 이미지 생성 도구의 새 결과다. 정확한 프롬프트와 입력 여부는 `src/image-prompts.json`에 보관했다. 공간 일러스트 4개와 파비콘은 직접 작성한 SVG이며 외부 폰트·라이브러리·원본 기업 코드·미디어를 포함하지 않는다.

이 기록은 기능·파일 검증이며 저작권 비침해나 상표 사용 가능성의 법률 의견서가 아니다. 공개 배포 성공 여부는 GitHub Actions 결과를 별도로 확인한다.
