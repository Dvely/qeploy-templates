# 루프선반 검증 기록

- 17개 화면, 890개 상대 링크·이미지·앵커 확인. 중복 ID와 외부 자산 참조 없음. SVG 파싱 확인.
- 320·390·1280px에서 17개 화면의 문서 가로 넘침, 완료된 이미지의 손상 없음. 페이지 제목 h1 각 1개.
- 캠페인 이전·다음, 일시정지와 상태 안내 확인. 1280×720에서 조작부 하단 705px로 첫 화면 안에 표시.
- 검색 모달에서 폴디드 노트 검색 시 2개 결과. 가격 오름차순에서 파동 아트 카드가 먼저 나옴. 포토북 분류와 빈 검색 결과 확인.
- 블루 룸 투명 블루 옵션 2개 담기 → 72,000원, 수량 3개 → 108,000원. 선택 해제 → 0원, 미리보기 비활성화. 구성 미리보기, Esc 닫기, 선택 삭제와 빈 화면 확인.
- 모바일에서 메뉴 열기·Esc 닫기, 320px의 실제 상품이 담긴 장바구니 가로 넘침 없음. 마지막 상품 삭제 후 상품 둘러보기 링크로 초점 이동.
- 상세에서 찜한 상품이 찜 목록에 유지되고, 해제하면 빈 화면이 표시됨.
- 전체 카탈로그 23종 빌드와 기존 배포 검증 테스트 4개 통과. 소스 압축물 36개 파일과 해시 검증.

실제 판매·결제·회원·배송은 구현하지 않았다. 원본 사이트에서 사진·로고·코드·전용 서체·실제 아티스트 콘텐츠를 가져오지 않았으며, 새 이미지 2종의 프롬프트와 자체 제작 SVG 기록을 포함한다. 이 기록은 법률상 비침해나 상표 사용 가능성을 보증하지 않는다.
