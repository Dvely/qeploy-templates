# 파도한상 검증 기록

2026-11-11 (한국 시간)

- 로컬 빌드에서 파도한상 포함 공개 템플릿 25개를 생성했다. 파도한상 HTML 20개에서 내부 파일·앵커 참조 1,101개를 검사했다.
- 브라우저에서 화면 20개를 너비 320px, 390px, 1280px로 열어 가로 넘침과 제목, 대표 이미지 로딩을 확인했다.
- 캠페인 수동 전환과 일시 정지, 모바일 메뉴의 레시피 진입, 상품 검색·카테고리·가격 정렬을 확인했다. 검색어를 넣고 참치 카테고리로 이동해도 가격 오름차순이 유지됐다.
- 상품 2종을 3개 담아 예상 합계 113,700원과 구성 미리보기를 확인했다. 전체 선택을 해제하면 0원이 표시되고 미리보기가 비활성화됐다. 선택 삭제 뒤 빈 장바구니의 상품 탐색 링크에 초점이 이동했다. 찜은 화면 이동 후에도 유지됐고 개별 해제가 가능했다.
- 배포 정책 테스트 4개가 통과했다. 배포용 원본 압축의 검토 목록 38개와 SHA-256, 검토 파일을 포함한 전체 39개 항목을 대조했다.
- 주문 기능은 이 브라우저에서만 동작하는 구성 미리보기다.
