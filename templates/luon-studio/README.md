# 루온 스튜디오

가상의 크리에이티브 스튜디오 웹사이트입니다. 정적 서버에서 `src/index.html`을 엽니다. 다른 템플릿과 외부 API 없이 실행됩니다.

## 구성

- 참고: https://www.crea-m.com/ko (2026-11-03 확인).
- 원본의 전체 화면 영상과 문구 전환, 고정 헤더, 스크롤 진입·숫자·프로젝트 모션, 작업 필터, 서비스 자동 캐러셀, 기술 소개, 저널 아코디언, 팀 소개, 모바일 메뉴·문의 흐름을 유지합니다.
- 새 이름·로고·문구·이미지를 사용합니다. AI로 제작한 사진·캠페인 아트·팀 일러스트 6장과 이를 활용한 Full HD 모션 영상 4개를 로컬로 포함합니다. 원본 홍보 영상은 포함하지 않습니다.
- 메인·영문 메인·소개·작업·작업 상세·기술·서비스·서비스 상세·프로젝트·저널·채용·문의의 HTML 25개가 연결됩니다. 외부 서비스와 추가 작업 링크는 관련 로컬 예시로 연결됩니다.
- 문의·인재풀·챗봇은 브라우저에서 흐름을 살펴보는 시연입니다. 개인정보와 첨부 파일을 전송하거나 실제 문의를 접수하지 않습니다. 원본의 분석 스크립트와 지도 API 키를 제거했습니다. 지도는 확대와 드래그가 가능한 가상 위치 예시입니다.
- 실제 회사의 제휴·프로젝트·수상·직원·연락처를 안내하는 사이트가 아닙니다. 루온의 프로젝트와 수치는 디자인 시연을 위한 창작 예시입니다.

## 수정

`luon-*.html`과 `index.html`에는 초기 HTML과 React 서버 스트림이 함께 포함됩니다. 문구·이미지를 바꿀 때 두 표현을 함께 수정합니다. `_next/`는 로컬 UI 번들이며 경로와 모션 구조를 보존해야 합니다. `luon-local.js`가 정적 파일 이동과 로컬 시연 응답을 처리합니다. 브랜드 토큰과 로고는 `luon-brand.css`, `assets/luon-logo.svg`에 있습니다.

`src/IMAGE-PROMPTS.md`에 최종 이미지 파일과 내장 이미지 생성 도구에 전달한 프롬프트를 기록했습니다. 저장소 루트의 `npm run build`로 데모와 독립 소스 압축 파일을 만듭니다.
