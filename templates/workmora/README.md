# 워크모라 오피스 룩북

[Office Lookbook](https://officelookbook.co.kr/)의 가구 분류와 탐색 흐름을 참고하여, 가상 브랜드 **WORKMORA / 워크모라**로 새로 만든 템플릿입니다. 페이지 이름·제품 이름·문구·사진은 새 콘텐츠로 구성했습니다. 기존 템플릿은 유지하며 `workmora`로 추가했습니다.

## 유지한 카테고리

- `브랜드 → 공간 → 분류 → 세부`의 4단계 탐색 구조.
- 공간 3개: 서재/홈오피스, 오피스, 책상/책장.
- 원본의 가구 분류 13개와 세부 항목 31개의 이름을 그대로 유지합니다.
- 브랜드 선택 두 항목은 가상 라인명 `WORKMORA OFFICE`, `WORKMORA HOME`으로 바꿨습니다.
- 인원·필요예산·세부공간·톤앤매너의 맞춤견적 단계와 원본 선택 항목을 유지했습니다.

분류와 세부 항목은 각각 독립적인 HTML 탐색 화면으로 연결되며, 모든 카테고리에 예시 제품이 있습니다.

## 화면과 동작

총 54개 HTML 화면, 가상 가구 구성 68개, 공간 사례 12개를 포함합니다.

홈 → 가구 컬렉션 → 분류·세부 탐색 → 제품 상세 → 관련 공간 → 견적 구성 → 상담 내용 확인으로 이어집니다. 맞춤견적은 네 가지 선택을 바탕으로 가까운 공간을 정렬하고 선택 조건을 상담 화면에 전달합니다. 후기 필터·이야기 입력, 지역 쇼룸 필터·방문 상담도 연결했습니다.

검색·정렬·더 보기·대표 이미지 변경·가구 담기·수량 변경·구성 제거가 동작합니다. 관심 가구 목록만 브라우저에 저장하며, 상담·후기 입력은 실제 서버 접수나 개인정보 저장 없이 화면에서 확인합니다. 제품과 규격, 쇼룸, 후기 및 예산은 가상의 예시 콘텐츠입니다.

## 실행과 수정

저장소 루트에서 `npm run build`를 실행하면 `site/t/workmora/`와 씨앗 압축 파일이 생성됩니다. `src/`는 정적 서버에서 독립적으로 실행할 수 있으며 외부 이미지·폰트·API를 요구하지 않습니다.

- `src/workmora-data.js`: 원본 분류 체계, 새 제품·공간 데이터, 맞춤견적 선택 항목.
- `src/workmora.js`: 필터·견적·후기·방문 상담 동작.
- `src/workmora.css`: `:root` 디자인 토큰과 공통 화면.
- `src/workmora-mobile.css`: 모바일·태블릿 배치.
- `src/workmora-category-*.html`, `src/workmora-detail-*.html`: 각 분류의 페이지 이름·소개 문구.

## 이미지 제작 정보

이미지 12종은 **내장 ImageGen 도구**로 새로 제작했습니다. 최종 파일은 `src/images/workmora-*.png`에 저장했습니다. 원본 사이트의 사진과 로고를 배포 자산으로 사용하지 않습니다.

전체 최종 프롬프트와 파일별 경로는 [image-prompts.json](src/image-prompts.json)에 기록했습니다. 오피스·회의실·라운지와 의자·데스크·수납·파티션·조명·원형/사각 테이블·서랍 사진이며, 자연광과 오크·아이보리·모스그린을 중심으로 통일했습니다.

Pretendard 가변 서체는 SIL Open Font License에 따라 포함했으며, 전문은 `src/fonts/Pretendard-OFL.txt`에 있습니다. 아이콘과 워드마크는 HTML/CSS 및 인라인 SVG로 작성했습니다.

## 검증

- 전체 54개 화면을 390px·1440px에서 확인: 이미지 누락, 가로 넘침, 실행 오류 없음.
- 주요 11개 화면을 320px·768px·1024px·1280px에서 추가 확인: 배치 및 이미지 정상.
- 모바일 전체 메뉴, 가구 분류·검색, 제품 상세·견적 담기, 4단계 추천·조건 전달·상담 확인, 후기 입력 및 지역 쇼룸 선택 흐름 확인.
- 정적 링크·이미지·스크립트·서체 경로와 중복 ID, 이전 브랜드·추적 스크립트 검사 완료.

이번 작업은 공통 화면과 주요 흐름 3개 묶음, 분류·세부 탐색 화면 44개, 검증·제작 문서 및 미리보기 1개 묶음으로 나누어 48개 커밋으로 구성했습니다.
