개인정보와 데모 안내

이 사이트는 모듈룸 스튜디오라는 가상 브랜드의 정적 웹 템플릿입니다.

문의 양식

입력한 이름, 이메일, 프로젝트 내용은 서버나 운영자에게 전송되지 않습니다. 브리프 미리보기와 파일 저장 기능은 현재 브라우저 안에서만 작동하며 페이지를 새로 열면 입력 내용이 초기화됩니다.

파일 저장

저장 버튼을 누르면 작성한 내용이 텍스트 파일로 이 기기에 내려받아집니다. 공용 기기에서는 사용 후 파일을 직접 삭제해 주세요.

외부 서비스

별도 분석·광고 스크립트와 외부 글꼴을 사용하지 않습니다. 사이트 접속에는 호스팅 제공자의 기본 운영 정책이 적용될 수 있습니다.

콘텐츠

프로젝트, 서비스 가격 계산, 커뮤니티 화면은 체험용 예시입니다. 실제 계약과 주문, 상담 접수 기능을 제공하지 않습니다.
