# 자산 제작 기록

모든 JPG는 이 프로젝트를 위해 ImageGen으로 제작했다. 각 파일의 전체 프롬프트는 `image-prompts.json`에 기록했다. 생성 원본에서 JPEG 품질 85로 인코딩했으며 별도 외부 사진은 사용하지 않았다.

`assets/mark.svg`는 높이가 다른 세 직사각형을 조합해 직접 그린 모듈룸 심벌이다. 웹의 입체 브라우저·휴대폰·분해된 링·점 조형은 자체 CSS와 Canvas 코드로 그린다. 기존 사이트의 3D 모델·영상·글꼴·사진을 포함하지 않는다.

프로젝트명과 브랜드, 설명은 자체 기획한 예시이며 실제 고객의 실적 또는 고객 후기가 아니다. 주소는 저장소의 기존 요청에 맞춘 동양미래대학교 주소를 표기하며, 실제 스튜디오 소재지로 주장하지 않는다.
