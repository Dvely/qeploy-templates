# 모듈룸 스튜디오

디지털 스튜디오의 콘셉트 포트폴리오. 19개 정적 페이지와 로컬 브라우저 인터랙션으로 구성한다.

- `src/content.mjs`: 여섯 콘셉트 프로젝트, 서비스, 저널 원고
- `src/build.mjs`: 홈·목록·상세·브리프 등 HTML 생성
- `src/site.css`: 입체 브라우저, 흑백 섹션, 반응형 화면
- `src/site.mjs`: 스크롤 모션, 포인트 조형, 탭, 메뉴, 필터, 로컬 브리프/견적 파일
- `src/image-prompts.json`: ImageGen 이미지 제작 프롬프트

루트에서 `node templates/modulroom-studio/src/build.mjs`로 독립 HTML을 생성한다. 생성된 `src/`를 정적 서버로 열 수 있다. 전체 공개 빌드는 `npm run build`를 사용한다.

메뉴·필터·서비스 탭은 키보드 조작을 지원한다. 입체 모션에는 멈춤 기능과 시스템 움직임 줄이기 설정을 적용한다. 문의 양식은 입력 내용을 서버로 보내지 않으며, 브리프를 미리 보고 텍스트 파일로 저장하는 체험 기능이다. 견적 도구의 금액도 예시이며 실제 가격이 아니다.

참고: https://incoding.co.kr/ 의 입체 화면 도입, 흑백 섹션 전환, 비대칭 포트폴리오 그리드, 서비스 전환과 넓은 편집형 레이아웃을 살펴보았다. 원본 코드·모델·사진·로고·고객 실적·문구를 포함하지 않는다. 가상 브랜드, 새 콘텐츠와 새 이미지, 독립 제작 CSS/Canvas 모션을 사용한다.
