# AQUAFOLIO · 아쿠아폴리오

Stitch의 심해 아쿠아리움 시안을 적용한 정적 템플릿입니다. 홈·생물 도감·프로그램·예매의 네 주요 화면과 소개·보존·관람 가이드·단체 문의·약관의 보조 화면을 연결했습니다. 정적 서버에서 `index.html`을 열면 됩니다. 이미지·폰트·스타일·스크립트는 모두 로컬 파일이며 외부 서비스 요청이 필요하지 않습니다.

- `index.html`: 홈, 생태 프로그램·전시·생물 소개, 가족·데이트·어린이 코스
- `aquafolio-creatures.html`: 생물 검색·분류·정렬, 일러스트레이션과 위치를 포함한 상세 모달
- `aquafolio-programs.html`: 일주일 날짜 선택, 프로그램 분류와 위치 상세, 특별 체험 선택 확인
- `aquafolio-tickets.html`: 현재 날짜 기준 달력, 권종 수량·할인·합계, 결제 수단 선택과 확인 모달, FAQ
- `aquafolio-about.html`, `aquafolio-conservation.html`, `aquafolio-guide.html`: 전시 소개, 보존 활동, 인쇄 가능한 관람 가이드
- `aquafolio-groups.html`: 단체 관람 문의 화면과 선택 확인
- `aquafolio-privacy.html`, `aquafolio-terms.html`: 체험 정보 처리와 이용 안내
- `aquafolio-data.js`: 생물·프로그램·체험·가격 콘텐츠
- `aquafolio.js`, `aquafolio.css`: 공통 동작, 테마 토큰과 모바일 배치

날짜는 서울 시간을 기준으로 표시합니다. 지난 날짜를 선택할 수 없으며, 입장권은 합산 10매·세트까지 선택할 수 있습니다. 월 이동과 빠른 날짜 선택, 홈에서 가족·연간권 선택, 프로그램에서 선택한 날짜의 입장권 연결을 제공합니다.

브랜드·전시·생물의 개체 이야기·운영 정보·요금·프로그램은 디자인 예시입니다. 실제 결제·예약 접수·발권·알림은 진행하지 않습니다. 생물 도감 내용은 제공된 시안의 콘텐츠로, 실제 생물 정보로 사용하기 전 운영자가 검토해야 합니다. 입력한 단체명·이름·이메일·연락처·문의는 저장하거나 전송하지 않으며, 일정 보관에는 선택한 날짜만 현재 브라우저에 남깁니다.

## 일러스트레이션 자산 안내

2026-11-06에 출처와 이용 허락을 확인할 수 없었던 사진·지도·썸네일 래스터 파일을 제거하고, Qeploy contributors가 직접 작성한 독창적인 SVG 일러스트레이션으로 교체했습니다. 원본 사진의 픽셀이나 외부 SVG 경로를 변환·복사하지 않았습니다. 이미지 영역은 이제 실제 인물·장소·상품 또는 진료 결과의 사진이 아닌 설명용 그림입니다. 지도형 그림은 실제 길찾기 용도가 아닌 개념도입니다.

새 SVG에는 상업적 이용·수정·소스 템플릿 재배포를 허용합니다. 파일별 교체 기록과 범위는 `ASSET-PROVENANCE.json`을 확인하세요. 이 안내는 새 그림에만 적용되며, 사이트 전체나 제3자 코드·서체·디자인에 대한 법적 검토 완료를 뜻하지 않습니다. 기존 설명에서 사진으로 지칭하던 영역은 이 일러스트레이션으로 대체됐습니다.
