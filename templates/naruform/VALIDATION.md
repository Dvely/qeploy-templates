# 나루폼 검증 기록

검증일: 2026-11-08

## 빌드와 배포 파일

- 전체 카탈로그 21종 빌드 통과. 나루폼 18개 화면 생성.
- 18개 HTML의 상대 링크·이미지·앵커 486개 확인. 누락·외부 자산 참조 없음.
- 소스 압축물 36개 파일의 목록과 SHA-256이 검토 기록과 일치.
- 직접 제작한 SVG 8종의 현재 해시가 제작 자료 기록과 일치.
- JavaScript·생성기·콘텐츠 구문 검사 통과. HTML의 원본 브랜드·대표 문구 잔존 없음.
- 기존 배포 검증 규칙 테스트 4개 및 변경 파일 공백 검사 통과.

## 브라우저

- 320×780, 390×844, 1280×800에서 18개 화면씩 확인. 문서 clientWidth 기준 가로 넘침 없음, 페이지마다 h1 한 개, 로드가 끝난 이미지 손상 없음.
- 처음 발견한 모바일 정렬 선택 상자의 고정 폭을 가용 폭에 맞도록 보정.
- 조형 장면 선택 후 선택 상태와 장면 설명 갱신 확인.
- 전체 메뉴 열기·Escape 닫기, 배경 main의 inert 적용과 복귀, 마지막 메뉴에서 Tab 시 닫기 버튼으로 순환 확인.
- 디지털 서비스 필터 2개, ‘커런트’ 검색 1개, 없는 검색어의 빈 결과, 조건 초기화, 이름순 정렬 확인.
- 작업 상세 → 해당 작업이 선택된 브리프, 서비스 펼침 → 해당 서비스가 선택된 브리프 연결 확인.
- 브리프 방향 미선택, 내용 미입력, 시연 확인 미체크 시 단계 진행 차단 확인.
- 예시 프로젝트명·내용 → 검토 → 완료 → 텍스트 파일 다운로드 확인. 처음부터 작성 및 새로고침 뒤 내용 초기화 확인.
- 브리프 내용은 메모리에서만 처리하는 구현이며 실제 전송·서버 저장·localStorage 저장을 하지 않는다.
- 실험실 슬라이더를 키보드로 조절해 회전 21°·간격 21 상태 확인. 블루 팔레트, 재생, 동작 줄이기 시 재생 중지, 설정의 새로고침 유지, 동작 설정 복귀와 실험 초기화 확인.
- 기록 ‘실험 기록’ 필터 1개 결과 확인.
- 검증 탭의 경고·오류 로그 없음. 임시 뷰포트는 기본 크기로 복구.

HTTP 정적 서버에서 확인했다. 실제 문의 접수·채용·외부 데이터 통신·서비스 운영은 구현하지 않았다. 실제 테스트 다운로드에는 가상의 예시 내용만 사용했다.

## 제작 범위

원본 사이트의 코드·미디어·3D 모델·폰트·문구·고객 실적을 가져오지 않았다. 우주·로켓·우주인 장면 대신 직접 작성한 추상 벡터와 CSS 조형 실험을 사용한다. 에셋별 제작 기록과 현재 파일 해시는 `src/ASSET-PROVENANCE.json`, `src/assets/art-record.json`, `src/DISTRIBUTION-REVIEW.json`에 있다.

이 기록은 기능·파일 확인이며 저작권 비침해·상표 사용 가능성을 보증하는 법률 의견서가 아니다. 공개 배포 성공 여부는 GitHub Actions 결과를 별도로 확인한다.
