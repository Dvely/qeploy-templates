# 제작 자료와 이용 범위

- 이 프로젝트의 코드·화면·문구·로고 도형·벡터·인터랙션은 새로 작성했다. 시스템 글꼴을 사용하며 외부 서체·아이콘 파일·3D 모델·유료 테마·사진·원본 사이트 코드/미디어를 포함하지 않는다.
- `signal-sculpture.svg`, `project-atrium.svg`, `project-current.svg`, `project-grain.svg`는 SVG 도형·곡선·그라데이션을 직접 작성했다. 제작 설명과 파일 해시는 `assets/art-record.json`에 있다.
- `project-field.svg`, `project-pulse.svg`, `project-index.svg`, `favicon.svg`는 `build.mjs`가 자체 도형과 좌표로 생성한다. CSS 실험실의 판 구조와 배경도 직접 작성한 도형이다.
- 원본의 우주·로켓·우주인·전용 HUD와 그래픽을 입력 또는 자산으로 사용하지 않았다. 미디어 생성 모델도 사용하지 않았다.
- 모든 작업·직무·에디토리얼은 창작 콘셉트이며 실제 고객·실적·채용·제휴를 나타내지 않는다.
- 브랜드명의 상표 선행 조사나 등록 가능성은 검증하지 않았다. 제작 기록과 파일 검사는 법률상 비침해 인증서가 아니다.
- LICENSE.txt는 이 프로젝트를 위해 새로 작성한 자료의 이용 범위를 다룬다.
