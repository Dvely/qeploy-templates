# 나루폼 독립 소스

`index.html`을 HTTP 정적 서버에서 열면 된다. 외부 라이브러리·폰트·API·원격 미디어가 필요하지 않는다. 상대 경로로 상세 화면을 연결했다.

## 수정

`content.mjs`의 가상 콘텐츠를 고친 뒤 `node build.mjs`를 실행한다. `build.mjs`는 18개 HTML, 파비콘과 제품 아닌 자체 그래픽 3종을 생성한다. 나머지 4개 SVG는 `assets/art-record.json`에 제작 방법을 기록했다.

- 회사·서비스·작업 목록과 상세·실험실·기록·직무 소개·프로젝트 브리프·이용 안내
- 작업 분류/검색/정렬/초기화, 기록 분류
- 추상 조형 장면 선택, 스크롤 진행 표시, 섹션 등장, 축소 동작 설정
- 키보드 슬라이더와 팔레트로 조절하는 CSS 조형 실험, 재생/정지/초기화
- 모바일 메뉴의 초점 순환·Escape 닫기·배경 비활성 처리
- 예시 프로젝트 브리프 작성/검토/텍스트 다운로드/초기화

브리프 내용은 메모리에서만 처리하고 전송하거나 localStorage에 저장하지 않는다. 저장하는 항목은 `naruform-reduced-motion`의 동작 축소 설정 하나뿐이다. 실제 이메일·개인정보·민감한 업무 내용을 입력하지 않는다.

브랜드·프로젝트·직무는 창작 예시이며 실제 실적·서비스·채용을 주장하지 않는다. 동양미래대학교의 주소는 학습용 예시이며 입주·제휴 관계를 뜻하지 않는다.
