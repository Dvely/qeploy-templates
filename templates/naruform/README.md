# 나루폼 · NARUFORM

생각의 결을 경험의 형태로 연결하는 가상의 디지털 스튜디오. 회사·서비스·작업 6종·기록 3종·실험실·브리프 시연을 18개 정적 화면으로 구성한다.

원본 사이트는 UI/UX의 일반적인 정보 흐름과 디지털 스튜디오라는 주제를 살펴보는 데만 사용했다. 원본의 우주·로켓·우주인·HUD 장면, 코드, 이미지, 모델, 전용 폰트, 문구, 고객 실적을 가져오지 않았다. 밝은 종이색·남색·코랄의 독립 디자인, 직접 그린 벡터, 조형 제어와 다른 화면 구성을 사용한다. 동일 복제나 법률상 비침해를 보증하는 프로젝트가 아니다.

- `node templates/naruform/src/build.mjs`로 HTML과 자체 생성 벡터를 갱신한다.
- `src/content.mjs`에서 창작 콘텐츠를 수정한다.
- `src/site.css`와 `src/site.js`에서 디자인과 동작을 수정한다.
- 전체 카탈로그는 저장소의 `npm run build`를 사용한다.
- 제작·파일 기록은 `src/ASSET-PROVENANCE.json`, `src/DISTRIBUTION-REVIEW.json`을 참고한다. 소스 변경 후 검토 기록을 갱신해야 배포할 수 있다.

실제 고객·채용·문의 접수 서비스가 아니다. 브리프는 현재 화면에서만 유지되고 다운로드할 수 있다. 저장소에는 동작 축소 설정만 보관한다.
