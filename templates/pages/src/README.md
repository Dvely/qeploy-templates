# PAGES 페이지스

도서 큐레이션, 북클럽, 작가 북토크를 연결하는 자기 완결형 서점 템플릿입니다. 이 폴더를 정적 서버에서 그대로 열 수 있으며 별도 설치나 외부 서비스 연결이 필요하지 않습니다.

- `index.html`: 서점 홈, 도서·모임 검색, 도서 분류, 문장 미리보기.
- `pages-book.html?book=garden`: 도서 상세. `garden`, `quiet`, `light`, `teacup`, `winter` 중 선택합니다.
- `pages-club.html?program=private`: 북클럽 상세. `private`, `classics`, `novels`, `philosophy`, `morning` 중 선택합니다.
- `pages-event.html`: 공간 인문학 북토크. `?program=reading`은 원서 낭독회입니다.
- `pages-data.js`: 도서명·가격·작가·분류·소개·표지 데이터.
- `pages.js`: 프로그램 데이터와 검색·보관함·장바구니·체험 신청 동작.
- `pages.css`: 컴파일된 정적 스타일. `:root`에서 색·서체·라운드 토큰을 조정합니다.

구매와 참가 신청은 체험용입니다. 이름·이메일·질문은 서버로 보내거나 저장하지 않습니다. 장바구니와 보관한 도서·클럽만 현재 브라우저의 `pages:` 저장 공간에 남습니다. 개인정보 안내에서 비울 수 있습니다.

이미지와 폰트는 모두 로컬 파일입니다. 화면에서 사용하지 않는 이전 서점 이미지와 외부 CDN 의존성은 제거했습니다. 폰트 및 스타일 라이선스는 `fonts/`와 `licenses/`에 포함되어 있습니다.

사용자가 지정한 Stitch PAGES 시안의 홈·도서·북클럽·북토크 네 화면을 바탕으로 구성했습니다. 도서·인물·연락처와 사업자 정보는 가상의 예시 콘텐츠입니다.
