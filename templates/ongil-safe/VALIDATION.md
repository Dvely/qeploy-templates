# 온길 세이프 검증 기록

검증일: 2026-11-08

## 코드·배포물

- 전체 카탈로그 20종 빌드 통과. 온길 세이프 25개 화면 생성.
- 25개 HTML의 로컬 링크·자산·앵커 945개 확인. 누락 및 외부 자산 참조 없음.
- 소스 압축물 47개 파일의 목록과 SHA-256이 검토 기록과 일치.
- JavaScript·생성기·콘텐츠 구문 검사 통과. HTML에 원본 브랜드·대표 문구 잔존 없음.
- 배포 검증 규칙의 기존 테스트 4개 통과. 변경 파일 공백 검사 통과.

## 브라우저

- 320×780, 390×844, 1280×800에서 25개 화면씩 확인. 문서 clientWidth 기준 가로 넘침 없음, 페이지마다 h1 한 개, 로드가 끝난 이미지의 손상 없음.
- 모바일 장식 이미지의 의도된 확대가 문서 가로 넘침으로 이어지지 않도록 hero에서 자르도록 수정.
- 모바일 메뉴 열기, Escape 닫기, 배경 inert 복귀 확인.
- 홈 사업 포인트 선택 후 설명과 상세 링크 갱신 확인.
- 제품 분류 2개 결과, 없는 검색어의 결과 없음 상태 확인.
- 관심 제품 4개 보관, 5번째 제한 안내, 새로고침 후 유지, 개별 제거, 전체 비우기 확인.
- 제품 상세 → 해당 제품이 선택된 문의 초안 연결 확인.
- 서비스·공간 미선택, 내용 미입력, 시연 확인 미체크 시 단계 진행 차단 확인.
- 예시 서비스·공간·회사·이메일·내용 → 초안 검토 → 완료 → 텍스트 파일 다운로드 확인.
- 처음부터 작성 및 새로고침 뒤 작성 내용 초기화 확인. 작성 내용은 localStorage에 저장하지 않는 구현.
- 가상 사례 ‘점검’ 필터 1개 결과, 소식 ‘관리 이야기’ 필터 1개 결과 확인.
- 검증 탭의 경고·오류 로그 없음. 임시 뷰포트는 기본 크기로 복구.

HTTP 정적 서버에서 검증했다. 실제 문의 전송·판매·안전 진단·긴급 대응은 구현하지 않았다. 다운로드한 문의 파일은 가상의 테스트 내용만 포함한다.

## 제작 자료

원본의 코드·사진·폰트·일러스트를 가져오지 않았다. 공간 이미지 1개는 참조 이미지 없이 새로 생성했고 정확한 프롬프트를 `src/image-prompts.json`에 기록했다. 서비스·제품·파비콘은 직접 작성한 SVG다. 파일별 제작 기록은 `src/ASSET-PROVENANCE.json`과 `src/DISTRIBUTION-REVIEW.json`에 있다.

이 기록은 기능·파일 검증이며 저작권 비침해나 상표 사용 가능성의 법률 의견서가 아니다. 공개 배포 결과는 GitHub Actions에서 별도로 확인한다.
