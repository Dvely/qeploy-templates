# 제작 자료와 이용 범위

- 화면·HTML/CSS/JavaScript·생성기·문구·로고 도형·벡터는 이 프로젝트를 위해 새로 작성했습니다. 기존 Qeploy 자체 코드의 일반적인 구현 패턴을 사용할 수 있으며 원본 기업 사이트 코드를 포함하지 않습니다. LICENSE.txt의 범위를 참고하세요.
- 공간 PNG는 OpenAI 내장 image_gen 도구에 image-prompts.json의 텍스트만 제공한 새 결과입니다. 원본 사이트의 이미지·스크린샷·로고를 입력으로 사용하지 않았습니다. 생성 결과의 독점적 저작권 또는 모든 제3자 권리의 부재를 보증하지 않습니다.
- 서비스 SVG 3종은 assets/vector-record.json에 제작 방법을 기록했고, 제품 SVG 6종은 build.mjs가 자체 도형으로 생성합니다. 제품 모양과 공간은 가상의 콘셉트이며 실제 규격·인증·성능·안전 지침이 아닙니다.
- 외부 서체·아이콘 파일·JavaScript/CSS 라이브러리·유료 테마·플러그인·원본 미디어를 포함하지 않습니다. 시스템 글꼴을 사용합니다.
- 브랜드·사업·제품·사례·직무는 창작 예시입니다. 실제 회사의 자격·실적·제휴·운영·채용을 주장하지 않습니다. 브랜드 이름의 상표 선행 조사·등록 가능성은 별도 확인이 필요합니다.
- 출처 기록과 해시 검사는 제작 자료·현재 파일의 일치를 확인하는 장치이며 법률상 비침해 인증서가 아닙니다.
