# 온길 세이프

사람·공간·준비를 연결하는 가상의 안전 서비스 기업 템플릿입니다. 화면·모션·문구·로고·벡터는 새로 작성했고, 공간 모형 PNG는 원본 이미지를 입력하지 않은 텍스트 생성 결과를 사용합니다.

## 화면과 동작

25개 화면: 홈, 소개, 사업 목록·상세 3종, 제품 목록·상세 6종, 공간 사례 목록·상세 4종, 소식 목록·상세 3종, 문의 초안, 가상 역할 소개, 시연 이용 안내.

홈의 공간 포인트와 사업 선택 버튼은 관련 서비스 설명·링크를 갱신합니다. 제품은 분류·검색할 수 있고 최대 4개의 관심 제품 ID만 브라우저에 보관합니다. 선택 제품과 서비스는 단계별 문의 시연으로 연결됩니다. 문의의 회사·기관명·이메일·내용은 메모리에서만 처리하며 서버 전송·브라우저 저장 없이 텍스트 초안으로 내려받을 수 있습니다. 실제 서비스·구매·채용·전문 진단·긴급 대응을 제공하지 않습니다.

## 실행과 수정

`src/`를 정적 서버로 제공합니다. 외부 폰트·JavaScript/CSS 라이브러리·네트워크 API·데이터 fetch가 없는 자체 완결형 템플릿입니다.

```sh
node templates/ongil-safe/src/build.mjs
```

- 콘텐츠: `src/content.mjs`
- 화면 생성: `src/build.mjs`
- 디자인·반응형·모션: `src/site.css`
- 탐색·문의 시연: `src/site.js`

생성기를 실행한 뒤 제작 기록과 실제 파일을 검토하고, 루트의 명시적 검토 기록 갱신 명령을 실행한 뒤 전체 빌드를 합니다. 일반 빌드는 미검토 변경을 자동 승인하지 않습니다.

## 참고와 독립 제작 범위

사용자가 제공한 `https://sunbousai.jp/`의 사업·제품·사례를 탐색하는 일반적인 흐름과 일러스트를 통한 공간 소개라는 아이디어를 참고했습니다. 원본의 마을 파노라마·언덕·인물·그래픽 경로·문구·GOOD PARTNER 레터링·전용 모션·HTML/CSS/JS·폰트를 복제하거나 가져오지 않았습니다.

새 구성은 단일 공간 모형, 서비스 포인트 선택, 별도 색상·로고·타이포그래피·서비스 카드·제품 검색·관심 목록·문의 초안 단계로 설계했습니다. 원본 레이아웃을 그대로 재현했다거나 모든 법적 위험이 없다고 주장하지 않습니다.

공간 PNG는 내장 이미지 생성 도구의 새 결과이며 `src/image-prompts.json`에 텍스트 프롬프트와 참조 이미지 미사용을 기록했습니다. 서비스 SVG 3개와 제품 SVG 6개·파비콘은 직접 작성한 벡터입니다. 항목별 범위는 ASSET-PROVENANCE.json, THIRD_PARTY_NOTICES.md, LICENSE.txt에 있습니다. 새 브랜드의 상표 선행 조사·등록 가능성을 검토 완료한 것은 아닙니다.

제품·사례·직무는 가상의 예시이며 실제 인증·규격·성능·수행 실적·채용을 나타내지 않습니다. 대학 주소는 학습용 예시로 실제 사업장·입주·제휴 관계가 아닙니다.
