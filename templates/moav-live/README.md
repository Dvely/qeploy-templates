# 모아브 라이브

가상 라이프스타일 콘텐츠 브랜드의 정적 사이트입니다. `src/`를 정적 서버에서 실행합니다. 메인 외 소개·사업·가치·소식·채용·지원·안내를 포함한 26개 HTML이 연결되어 있습니다.

## 화면과 동작

- 참고: https://corp.cjonstyle.com/ko (2026-11-02 확인).
- 원본의 섹션 순서, 전체 화면 영상, 스크롤 잠금과 섹션 전환, 원형 빛과 문구 애니메이션, 채널 런처, 크리에이터 카드 이동, 상품 회전 갤러리, 가치·뉴스·채용·푸터 배치를 유지했습니다.
- 데스크톱 메뉴와 모바일 전체 메뉴·하위 항목, 오른쪽 섹션 이동 버튼, 카드·탭·아코디언은 로컬 UI 번들로 동작합니다.
- 새 이름·로고·문구와 생성 이미지 9장을 적용했습니다. 원본 영상 대신 새 사진으로 만든 12초 영상이 재생됩니다. 이미지 생성 프롬프트와 최종 파일은 `src/IMAGE-PROMPTS.md`에 기록했습니다.
- 원본 서버 없이 페이지를 이동하도록 `moav-local.js`에서 경로를 연결합니다. 영문 버튼은 영문 메인으로 이동합니다. 하위 페이지는 한글 콘텐츠입니다.
- 외부 분석 스크립트 실행과 외부 데이터 전송을 차단했습니다. 실제 문의·입점·신고·입찰·채용·주문은 접수하지 않습니다. 외부 서비스 버튼은 관련 로컬 소개로 연결하며 자료 버튼은 모아브 소개서 예시를 엽니다.

## 수정 위치

`src/index.html`과 `moav-*.html`은 서버 렌더링 HTML과 React 스트림을 함께 포함합니다. 문구를 수정할 때 두 표현을 일치시켜야 합니다. 원본 UI 클래스와 `_next/` 경로는 동작에 필요합니다. `moav-assets.js`는 이미지 이름을 새 로컬 파일로 연결합니다. 새로운 콘텐츠는 `assets/`와 브랜드 CSS·SVG에서 관리합니다.

이미지·영상·폰트·스타일·스크립트는 모두 이 템플릿 안에 있습니다. 다른 템플릿 파일과 서버 API를 요구하지 않습니다. 저장소 루트의 `npm run build`로 데모와 독립 소스 압축 파일을 생성합니다.
