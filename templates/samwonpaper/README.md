# 삼원페이퍼

[삼원페이퍼 공식 웹사이트](https://www.samwonpaper.com/)의 공개 화면을 2026-10-14에 확인하여 만든 로컬 프런트엔드 미리보기입니다. 기존 템플릿을 대체하지 않고 `samwonpaper`로 추가했습니다.

## 구성

- 원본 사진, 로고, Pretendard 서체, CSS를 바탕으로 한 홈과 접이식 배너·종이 카드·스크롤 효과.
- 메뉴와 고객지원, 공개 소식·다운로드 상세 등 54개의 HTML 화면.
- 현재 목록에서 확인한 종이 제품 60개의 실제 설명과 이미지. 공통 상세 화면과 컬러칩 선택으로 연결됩니다.
- 현재 포함된 컬렉션의 로컬 검색·정렬·페이지 이동 및 전체 메뉴, 팝업, FAQ.
- 1200px 미만에서 모바일 헤더·전체 메뉴·검색·카드·문의 화면을 재배치합니다.
- 표시용 큰 이미지 250개를 최대 2560px, WebP 품질 94로 최적화했습니다. 다운로드용 원본 파일과 애니메이션 GIF는 유지했습니다.

## 실행

저장소 루트에서 `npm run build`를 실행한 후 `site/t/samwonpaper/index.html`을 정적 서버로 열 수 있습니다. 별도 API 키나 계정은 필요하지 않습니다.

## 로컬 미리보기 범위

문의·투어 신청은 브라우저에서 입력과 필수 항목을 확인하고 안내 창을 표시합니다. 실제 접수, 예약 가능 여부, 개인정보 저장·전송을 처리하는 서버는 포함하지 않습니다. 제품 검색은 포함된 공개 목록을 대상으로 합니다. 원본의 전체 카탈로그 및 과거 아카이브 데이터를 모두 수집하지는 않았습니다.

인스타그램 실시간 위젯은 원본 서비스의 접근 제한으로 가져올 수 없어 같은 그리드에 공식 사이트의 소식·종이 사진을 표시합니다. 실시간 상담·SNS 피드·외부 지도 서비스는 내장하지 않았습니다. 외부 구매·SNS 링크는 원래 공개 사이트로 연결됩니다.

## 출처와 서체

화면 구성, 브랜드명, 이미지와 콘텐츠의 출처는 삼원페이퍼입니다. 원본의 저작권 표기를 유지했습니다. 이 미리보기를 원본의 공식 서비스로 표시하지 않으며, 원본 콘텐츠에 대한 권리를 새로 부여하지 않습니다.

Pretendard는 [공식 저장소](https://github.com/orioncactus/pretendard)의 v1.3.9 가변 서체를 사용합니다. SIL Open Font License 전문은 `src/fonts/Pretendard-OFL.txt`에 포함했습니다.

원본이 사용하는 jQuery 3.4.1, jQuery UI, Swiper 8, imagesLoaded, GSAP 3.11, ScrollMagic과 프런트엔드 UI 스크립트를 화면 재현에 사용했고 배포 파일의 라이선스 헤더를 보존했습니다. 원본의 분석·광고·상담 추적 스크립트와 서버 제출 코드는 포함하지 않습니다.
