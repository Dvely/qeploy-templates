# 제작 자료와 제3자 고지

ASSET-PROVENANCE.json에 포함 파일별 제작/이용 근거와 해시를 기록했습니다.

- 새 SVG 일러스트는 Qeploy contributors가 직접 작성했습니다. 벡터에 관해 상업적 이용·수정·웹 표시·독립 소스 템플릿 동봉과 재배포를 허용합니다. 다른 자료에 대한 권리까지 허락하는 것은 아닙니다.
- 생성 사진이 포함된 경우 해당 제작 기록을 연결했습니다. 생성 미디어의 독점권이나 제3자 권리 부재를 보증하지 않습니다.
- fonts/의 글꼴은 각 OFL 전문 및 저작권 고지를 유지해야 합니다.
- licenses/가 있는 경우 Tailwind의 MIT 고지를 유지합니다. 이 고지가 사진이나 다른 자료의 권리를 부여하지 않습니다.
- 기존 시안에서 발전시킨 프로젝트 소스는 새 일러스트의 제작 증명과 별개입니다. 브랜드·콘텐츠를 추가할 때 원출처와 허용 조건을 다시 확인해야 합니다.
- 대학 주소는 학습용 예시 위치이며 실제 사업장·입주·제휴 관계를 주장하지 않습니다.
