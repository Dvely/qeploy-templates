# 온결 하우스 · ONGYEOL HAUS

[우딘 공개 사이트](https://www.wood.co.kr/)의 메인 화면, 메뉴, 제품 분류와 상세 화면을 2026-10-14에 브라우저로 확인하여 재구성한 독립 템플릿입니다. 기존 템플릿은 유지하고 `ongyeol-haus`로 추가했습니다.

## 구성

- 원본의 큰 사진, 고정 헤더, 4점 전체 메뉴 버튼, 화면 높이 중심의 여덟 섹션, 추천 제품 분할 배치, 카테고리 그리드, 어두운 쇼룸, 갤러리 가로 목록, 브랜드, 미디어·저널 흐름을 반영했습니다.
- 로고·사이트명·문구·제품명·사진은 가상의 **온결 하우스**로 교체했습니다. 원본 로고·사진·실제 연락처·광고 추적기·SNS 위젯은 포함하지 않습니다.
- HTML 91개: 홈·브랜드·스토리·제품·갤러리·쇼룸·고객지원 등 15개, 소재 분류 8개, 세부 목록 32개, 제품 상세 32개, 공간 상세 4개.
- 분류: 도어, 중문, 몰딩, 시트·인테리어필름, 보드, 마루, 창호, 목재. 브랜드를 포함한 원본 세부 이름은 온결 브랜드에 맞게 변경했습니다.
- 사진 6개는 내장 `image_gen`으로 새로 생성한 로컬 PNG입니다. 프롬프트 및 최종 파일은 `image-prompts.json`에 기록했습니다. 제품 사진은 독립 제품 실측 사진이 아닌 공간·소재 연출 예시입니다.
- 메인 자동 페이드(5초), 일시정지·이전·다음, 추천 제품·쇼룸 사진 이동, 접근 가능한 전체 메뉴, 검색·검색 결과 없음, 목록 검색, 갤러리 필터, 상세 사진·마감 선택, 제품을 이어받는 상담, FAQ, 가이드 다운로드, 소재 북 인쇄.
- 데스크톱의 여백과 사진 비율을 유지하고 1024px 이하에서 일반 문서 흐름으로 전환합니다. 640px 이하에서 메뉴·사진·카드·제품 정보·폼을 별도로 재배치합니다. 동작 줄이기 설정을 지원합니다.

## 생성·실행

```sh
node templates/ongyeol-haus/generate.mjs
npm run build
```

`site/t/ongyeol-haus/`를 정적 서버로 엽니다. 생성기는 `src/ongyeol-data.js`, `src/ongyeol-views.js`를 읽어 독립 HTML과 가이드 파일을 만듭니다. 시드 압축에는 완성된 HTML, 스크립트, 사진·서체가 모두 포함되어 별도 생성 작업 없이 정적 서버에서 동작합니다. 시드 안에서도 `node generate.mjs`로 데이터를 HTML에 다시 반영할 수 있습니다. 이미지·글꼴·화면 간 링크는 템플릿 내부 경로만 사용합니다.

## 시연 범위

온결 하우스와 모든 제품·공간은 가상 콘텐츠입니다. 실제 인증·시공 실적·회사 연혁·고객 후기·주소·연락처를 만들어 표시하지 않습니다. 상담·쇼룸 예약·A/S·파트너 문의는 필수 입력 확인과 작성 내용의 화면 확인까지 동작하며 **외부 제출, 실제 예약, 개인정보 저장은 하지 않습니다**. 실제 서비스 적용 시 운영 정보와 서버·개인정보 처리 절차를 연결해야 합니다.

미디어 영역은 새 제작 사진과 소재 이야기 모달로, 소셜 영역은 내부 공간 저널로 변경했습니다. 원본의 동영상과 실제 SNS 계정은 재사용하지 않습니다. 카탈로그는 인쇄 가능한 소재 북과 UTF-8 텍스트 가이드 8개를 제공합니다. 제품 사양과 관리 내용은 예시이며 실제 공급사의 지침을 대체하지 않습니다.

## 자산

새 로고는 텍스트 로고와 직접 제작한 SVG 심볼입니다. Pretendard 가변 서체는 SIL Open Font License로 제공되며 전문은 `src/fonts/Pretendard-OFL.txt`입니다. 사진 생성에는 원본 이미지나 참고 사진을 입력하지 않았습니다.

## 확인

- `npm run build` 성공, 템플릿 카탈로그에 `ongyeol-haus` 포함.
- 91개 HTML의 로컬 링크·이미지·다운로드·앵커와 중첩 링크 검사 통과.
- 91개 화면을 390px·1440px에서 각각 확인하고 주요 화면을 320px·768px·1024px에서 추가 확인한 211개 화면·크기 조합에서 가로 넘침, 화면 밖 텍스트 블록, 누락 이미지가 발견되지 않았습니다.
- 검색 → 상세 → 마감 선택 → 상담 제품·마감 이어받기 → 필수 입력·시연 결과 확인, 전체메뉴, FAQ, 갤러리 필터, 목록의 검색 결과 없음 안내를 브라우저에서 확인했습니다.
